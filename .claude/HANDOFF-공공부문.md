# 인수인계 — 공공부문(알리오)

작성 2026-08-20 · **공공부문 붙이기는 끝났다.** 아래는 어떻게 풀었는지와 남은 일이다.

## 끝난 것 — ⑩ 공공부문

`public_sector.py` → `docs/public_sector.json` + `docs/ps/NN.json` → `index.html` 의 ⑩ 카드.
알리오 355곳, 21개 항목, 6개 연도. 키 불필요. 워크플로에 붙어 매일 돈다.

### 막혔던 CSV 파일명 문제 — 풀 필요가 없었다

이전 세션은 `statisticsDown.json?f=…&s=…` 의 `s=` 규칙을 찾으려 했다. 그 방향은 막다른 길이다.
`일반현황`은 화면에 하드코딩된 특수 케이스라 되는 것이었고, 항목별 파일명은 서버가 쥐고 있다.

**화면이 실제로 쓰는 JSON 이 따로 있다.** `/resources/vue/app.js` 에서 찾았다.

```
GET /statisticsSearch/findSingleItemSearchList.json
    ?pageNo=1&countPerPage=100&reportFormNo=<rf>&itemNo=<ino>
```

- `treeCode` = `"<reportFormNo>-<itemNo>"` (findItemTreeList.json 의 각 잎 노드)
- 응답: `{status:"success", data:{result:[...], page:{totalPage,...}}}`
- 한 행 = 한 기관 × 6개 연도(`yy5`..`yy0`) + `apbaId/apbaNa/apbaTypeNm/jidtDptmNa/itmsUnitNm`
- `countPerPage` 상한은 **100**. 355곳이면 4쪽을 돈다.
- CSV 파싱도, 인코딩 씨름도, 파일명 추측도 없다.

관련 다운로드 엔드포인트(`downExcelSingleItem.json`)도 확인했지만 쓸 이유가 없다.

### 반드시 알고 있어야 할 함정 세 가지

1. **연도 기준이 섞여 있다.** 알리오 각주 그대로: `yy5`..`yy1` = 결산, `yy0`(=당해년도) = **예산편성** 기준.
   실제로 한전은 결산 96,381천원 → 예산 87,389천원으로 뚝 떨어진다. 섞어 평균 내면 안 된다.
   화면의 기본 비교는 결산 마지막 해만 쓴다(`psLast`).
   `GB_alioYear` 는 화면에서 정규식으로 읽는다 — 하드코딩하면 해가 바뀔 때 조용히 틀린다.

2. **단위를 짐작하면 틀린다.** `평균근속연수`는 '년'이 아니라 **월**로 온다(`itmsUnit=5`).
   그래서 수집기는 우리가 적어 둔 단위 대신 **응답의 `itmsUnitNm` 을 따르고**, 다르면 diag 에 WARN 을 남긴다.

3. **중간 노드는 값이 안 온다.** `20202-GI020102`(일반정규직>현원)처럼 자식이 있는 노드는 0건이다.
   잎인 `20202-GI02010201`(현원>계)을 써야 한다.

그리고 **0 이 '없음'인 항목이 있다.** 신입사원 초임 0은 0원이 아니라 그 해 신규채용이 없었다는 뜻이다
(대한석탄공사·한국통계정보원). 중위값과 등수에서 빼고, 근속 모형도 계산하지 않는다.

### 설계 결정 (지킨 것)

- **기능별 11개 분류** — 알리오 공식 분류(공기업/준정부/기타)는 법적 지위라 임금 비교에 못 쓴다.
  기관명 규칙을 먼저 보고, 안 걸리면 주무부처로 넘긴다. 기관명이 부처보다 안정적이다
  (2026년 개편으로 기후에너지환경부·산업통상부·재정경제부·지식재산처 등으로 이름이 다 바뀌었다).
  **연구·학술 규칙이 맨 앞**이다 — 에너지경제연구원의 노동시장은 발전소가 아니라 다른 출연연이다.
  분류 근거를 기관마다 `why` 로 실어 화면에 표시한다. 우리가 만든 분류라고 못 박아 뒀다.
  conects 사이트는 **분류 체계만 참고**했고 데이터 출처로 쓰지 않았다.
- **④ 로직을 쓰지 않았다** — 공공기관은 이익이 없어 지불능력 계산이 성립하지 않는다.
  총인건비 인상률은 기재부 지침 소관이고 공개 API 가 없어 **이용자 직접 입력**이다.
  대신 355곳 평균보수의 전년비 중위값을 같이 보여준다 — 지침 수치가 아니라 **실제 결과**라
  "지침대로 올렸는데 왜 체감이 다른가"를 물을 수 있다.
- **성별 격차를 근속으로 분해한다** — DART 에 없는 축이라 여기서만 가능하다.
  `보수 = 신입 초임 + (근속 1년당 증가분 × 근속)` 직선을 그 기관 공시값만으로 세운다.
  초임을 절편으로 쓰는 게 핵심 — 비례로 두면 근속 0년의 보수가 0원이 되어 격차가 부풀려진다.
  직종 구성이 갈리는 기관(병원 등)엔 안 맞는다고 화면에 크게 적어 뒀다. 결론이 아니라 질문의 출발점이다.
- **실패하면 조용히 넘기고 로그를 남긴다** — 항목별로 독립 실패하고, 전부 실패할 때만 기존 파일을 보존한다.
  원인은 출력 JSON 의 `diag` 배열에 남는다. 트리에서 코드가 사라지면 먼저 걸린다.
