# 인수인계 — 공공부문(알리오) 붙이기

작성 2026-08-20. 다음 세션이 이 파일만 읽고 이어갈 수 있게 적는다.

## 목표

④⑤⑥은 상장사(DART)만 다룬다. 공공기관 노동자·노조도 쓸 수 있게
알리오(공공기관 경영정보 공개시스템) 자료로 별도 카드를 만든다.

## 확인 끝난 것

**알리오는 로그인도 API 키도 필요 없다.** data.go.kr 가입은 불필요하다
(검색해 보니 채용정보와 지방공공기관 경영정보만 있고 임직원 보수는 없다).
알리오플러스(alioplus.go.kr) API도 시설·행사·사업 정보라 무관하다.

### 되는 엔드포인트

```
GET https://alio.go.kr/statisticsSearch/findItemTreeList.json
    → 항목 트리 603개. {status, data:[{id, pId, name, reportFormNo, itmsNo, ...}]}

GET https://alio.go.kr/download/statisticsDown.json?f=<한글파일명>&s=<영문파일명>
    → CSV 직접 다운로드. 키 불필요.
    실증: f=일반현황_2026.csv&s=general_status_2026.csv
          → 855KB, 355개 기관, 헤더 =
            No,기관명,기관유형,주무부처,설립근거,설립일,설립목적,주요기능 및 역할,
            기관연혁,경영목표 및 전략,기관장,기관장 임기,기관장 주요경력,도시명,
            상세주소,홈페이지,사업자번호,상위기관
```

### 필요한 항목의 코드 (findItemTreeList.json 에서 확인)

| 항목 | reportFormNo | 경로 |
|---|---|---|
| 임직원수 | `20202` | I. 기관운영 > 임직원수 |
| 1인당 평균 보수액 | `20601` | I. 기관운영 > 직원 평균보수 현황 > 직원평균보수 > 정규직(일반정규직) |

트리에 있는 다른 유용한 항목: `임직원 총계`, `무기계약직 정원/현원`,
`전일제/단시간`, `상임임원 평균보수`, `급여성 복리후생비`,
**`1인당 평균 보수액 (남성)` / `(여성)`**, `신규채용 현황`.

무기계약직이 별도로 잡히고 성별 보수가 기관별로 나온다 — DART 에는 없는 축이다.

## 막힌 지점 — 여기서부터 하면 된다

CSV 의 `s=` 영문 파일명 규칙을 못 찾았다. `general_status_2026.csv` 는 되지만
아래 후보는 전부 HTML 오류 페이지(1,161B)를 돌려준다.

```
employee_2026.csv / employee_status_2026.csv / staff_2026.csv / emp_status_2026.csv
employee_num_2026.csv / 20202_2026.csv / salary_2026.csv / average_salary_2026.csv
employee_salary_2026.csv / pay_2026.csv
```

다운로드 함수는 파일명을 인자로 받는다(`/resources/portal/js/downloadUtils.js`).

```js
function downStatisticsExcel(fileName, saveName, callBackFn) {
    formLocation('/download/statisticsDown.json?f=' + fileName + '&s=' + saveName);
}
```

즉 서버가 항목 선택 시점에 파일명을 내려준다.

### 푸는 방법 (권장 순서)

1. 브라우저로 `https://alio.go.kr/statisticsSearch/singleStatisticsSearch.do` 를 열고
   항목 트리에서 **I. 기관운영 > 임직원수** 를 실제로 선택한다.
2. CSV 버튼을 누른 뒤 네트워크 요청에서 `statisticsDown.json?f=…&s=…` 의 실제 값을 읽는다.
3. 항목을 바꿔 가며 몇 개 더 관찰해 규칙을 잡는다(연도 부분이 `_2026` 인지 등).
4. 규칙이 안 보이면, 트리 선택 시 서버로 가는 XHR(항목 → 파일명 응답)을 찾아
   그 엔드포인트를 직접 호출한다.

## 설계 결정 (이미 정한 것)

### 기관 분류는 기능별로

알리오 기본 분류는 공기업/준정부기관/기타공공기관인데 **법적 지위**라 임금 비교에
쓸모가 없다(같은 '기타공공기관'인 산업은행과 국립생태원을 비교하는 셈).

`public.conects.com/news/yearly_pay` 가 쓰는 11개 기능별 분류를 참고한다 —
검사검증 / 고용보건복지 / 금융 / 농림수산환경 / 문화국민생활 / 산업진흥정보화 /
에너지 / 외교법무 / 연구교육 / SOC / 기타.
상장사 쪽을 표준산업분류로 묶은 것과 같은 발상이다.

**단, 그 사이트를 데이터 출처로 쓰지 않는다.** 원본이 알리오이고, 교섭 자료의
출처가 수험 학원 사이트면 신뢰도가 떨어지며, 상업 사이트 가공물의 자동 수집은
약관 문제가 생길 수 있다. 분류 체계만 참고한다.

### 신입 초봉을 평균 보수와 함께 낸다

평균 보수는 근속·직급 구성에 좌우되지만 초봉은 그렇지 않아 기관 간 비교가 깔끔하다.

### ④ 로직을 그대로 쓰면 안 된다

공공기관은 이익이 없어 '지불능력' 계산이 성립하지 않는다. 기재부
「공기업·준정부기관 예산운용지침」의 총인건비 인상률이 상한을 정하는 구조다.
그 지침 수치는 API 가 없으므로 수동 입력 또는 연 1회 갱신으로 다룬다.

### 스크래핑이 아니라 CSV 다운로드다

그래도 화면 구조가 바뀌면 깨질 수 있다. 실패 시 조용히 넘어가고 **로그를 남기도록**
만든다. 이 프로젝트에서 ECOS·KOSIS 진단을 넣어 원인을 특정했던 방식과 같다.
