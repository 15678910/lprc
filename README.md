# lprc

**나의 실질임금 · 임금단협 · 노동 양극화 해소 계산기**

임금 교섭에서 **노동측의 생계비 근거**와 **사측의 지불능력 근거**를 같은 화면에 놓는 계산기입니다.
어느 쪽 주장도 대변하지 않고, 공개 통계와 이용자 입력값으로 계산한 결과만 보여줍니다.

브라우저에서만 동작하며 서버가 없습니다. 입력값은 이 기기에만 남고 어디로도 전송되지 않습니다.

---

## 무엇을 답하나

| 질문 | 화면 | 근거 데이터 |
|---|---|---|
| 내 임금은 실제로 오른 게 맞나 | ①②③ 실질임금 | 내 소비 구성 + 품목별 물가 + 임금지수 |
| 회사는 얼마나 줄 수 있나 | ④ 임금단협 | DART 매출·영업이익·인건비 |
| 같은 일인데 왜 임금이 다른가 | ⑤ 격차 측정 | 공시 인원 구성 + 직접 입력 실태 |
| 좁히는 데 얼마·몇 년인가 | ⑥ 해소 경로 | 위 값들로 계산 |
| 공공기관은 어떤가 | ⑩ 공공부문 | 알리오 355곳 보수·근속·고용구조 |

④⑤⑥ 은 DART 공시에 기대므로 **상장사만** 다룹니다. 공공기관 노동자·노조는 ⑩ 을 씁니다.
알리오는 355곳이 **같은 서식으로** 공시하기 때문에 기관 간 비교가 오히려 깨끗하고,
DART 에 없는 축이 세 개 더 있습니다 — **성별 보수·근속**, **무기계약직 보수**,
**소속외인력(파견·용역·사내하도급) 인원**.

공식 물가가 담지 못하는 두 가지를 직접 넣습니다.

- **대출이자** — 국제 기준(COICOP)상 이자는 소비가 아니라 금융거래로 분류돼 물가지수에서 빠집니다
- **신규 구독료** — 물가는 '같은 물건의 가격 변화'를 재지 '없던 지출'은 재지 않습니다

## 구조

```
lprc/
├─ docs/                    GitHub Pages 로 서비스되는 정적 파일
│    index.html            계산기 본체 (단일 파일, 외부 라이브러리 없음)
│    guide.html            소개 · 이용 방법
│    future.html           AI 시대의 노동
│    about.html            이용 안내 · 출처 · 면책
│    robots.txt            검색엔진·LLM 학습 수집기 거부
│    money_macro.json      ← money_macro_monitor.py 생성
│    wage_negotiation.json ← wage_negotiation.py 생성 (목록)
│    co/NN.json            ← 〃 업종별 상세 (회사를 고른 뒤에 받는다)
│    public_sector.json    ← public_sector.py 생성 (목록)
│    ps/NN.json            ← 〃 기능별 상세 (기관을 고른 뒤에 받는다)

├─ money_macro_monitor.py   물가·임금·통화량·노동몫·가계소비·성장임금격차
├─ wage_negotiation.py      회사별 지불능력 (DART 직원현황 + 손익)
├─ public_sector.py         공공기관 보수·근속·고용구조 (알리오)
├─ core/                    환경변수·시크릿 로더
└─ .github/workflows/data.yml   매일 KST 10:00 (회사 재무는 일요일만)
```

큰 자료는 **쪼개서 필요한 것만 받습니다.** 전 상장사 1,883곳과 공공기관 355곳을
한 파일에 담으면 회사를 고르지도 않은 사람까지 그걸 받게 됩니다.
첫 화면은 가벼운 목록만 쓰고, 대상을 고른 뒤 그 업종·그룹 파일 하나를 받습니다.
같은 파일이 '업종·그룹 내 위치' 비교군도 겸합니다.
공공부문 목록(66KB)은 ⑩ 카드에 스크롤이 가까워질 때 받으므로,
거기까지 내려가지 않는 이용자는 아예 받지 않습니다.

수집기는 **표준 라이브러리만** 사용합니다. 설치할 의존성이 없습니다.

## 실행

### 화면만 보기

`docs/` 아래 파일을 웹서버로 띄우면 됩니다.
`file://` 로 직접 열면 브라우저 보안 정책 때문에 JSON 을 못 읽습니다.

```bash
python -m http.server 8000 --directory docs
```

→ http://localhost:8000

### 데이터 수집

```bash
python money_macro_monitor.py     # 키 없이도 대부분 수집됨
python wage_negotiation.py        # DART_API_KEY 필요
python public_sector.py           # 키 불필요 (알리오)
```

| 키 | 없으면 | 발급 |
|---|---|---|
| `DART_API_KEY` | ④⑤⑥ 회사 목록이 비고 수동 입력만 가능 | opendart.fss.or.kr (무료) |
| `BOK_API_KEY` | 서울 아파트 실질가격·한국 분배지표만 빠짐 | ecos.bok.or.kr (무료) |
| `FRED_API_KEY` | 일부 계열만 영향 (대부분 키 없이 동작) | fred.stlouisfed.org (무료) |
| `KOSIS_API_KEY` | ⑧ 평균 가구원 수(1인당 주거부담 환산)가 빠짐 | kosis.kr 오픈API (무료) |

환경변수 또는 GitHub Actions Secrets 로 넣습니다.
**키를 코드나 커밋에 넣지 마세요.**

## 검색 비노출

`robots.txt` 로 전체 경로를 막고 모든 페이지에 `noindex, nofollow` 를 넣었습니다.
GPTBot·ClaudeBot·Google-Extended·CCBot 등 언어모델 학습 수집기도 명시적으로 거부합니다.

다만 `robots.txt` 는 **요청이지 차단이 아닙니다.** 규칙을 지키는 수집기만 따릅니다.
링크를 아는 사람은 볼 수 있는 공개 페이지라는 점은 그대로입니다.

이 도구는 **투자자문도 노무·법률 자문도 아닙니다.**

- 교섭의무의 범위, 파견·도급 구분, 직접고용 의무 같은 판단은 법률 영역이며
  공인노무사·변호사의 확인이 필요합니다.
- 민간 기업의 고용형태별 급여와 간접고용 실태는 **DART 공시에 없어** 이용자 입력값에 의존합니다.
  협상 자료로 쓸 때는 출처를 반드시 함께 밝히세요.
  (공공기관은 알리오가 소속외인력 **인원**을 공시하므로 ⑩ 에서 자동으로 채워집니다. 임금은 공시되지 않습니다.)
- ⑩ 의 **기능별 11개 분류는 이 도구가 만든 것**이며 알리오의 공식 분류가 아닙니다.
  기관마다 어떤 규칙이 걸렸는지 화면에 함께 표시하니 확인하고 쓰세요.
- ⑩ 은 **중앙 공공기관만** 다룹니다. 지방공기업·지방출자출연기관은 클린아이 소관이라 빠져 있습니다.
- 공시에서 자동으로 가져온 값도 연결/별도 기준과 급여 포함 범위가 회사마다 달라,
  원문 사업보고서로 교차 확인해야 합니다.

자세한 한계는 `docs/about.html` 에 전부 적어 두었습니다.
