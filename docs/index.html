📋 출처 · 면책

데이터가 어디서 오고 언제 갱신되는지, 무엇이 아닌지(투자·노무 자문 아님), 개인정보를 왜 수집하지 않는지.

누구를 위한 것인가

  • 교섭 담당자 — 요구안의 근거를 숫자로 만들고 상대 주장을 검증할 때
  • 비정규직·하청 노동자 — 격차의 크기와 좁히는 비용을 특정하고, 원청과 마주 앉는 경로를 찾을 때
  • 사측 실무자 — 인상 시나리오가 손익에 미치는 영향을 미리 볼 때
  • 공공기관·공무원 노조 — 정부가 정한 기준에 정부가 미달하는지 볼 때
  • 주민·학부모 — 우리 지역에서 만든 가치가 어디로 가는지, 노동자가 주민으로서 설 자리가 어디인지 볼 때
  • 연구자·기자 — 공시와 통계로 회사·지역을 비교할 때
원칙 — 어느 쪽 주장도 대변하지 않습니다. 과장하면 반박당하므로 한계를 화면에 그대로 적습니다. 모든 숫자에 출처와 기준 시점을 붙이고, 이용자가 넣는 값은 서버로 보내지 않습니다.
